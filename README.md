# LEDGER - 수입·지출·투자 가계부

결제 문자, 카드 앱 알림, 영수증 사진을 넣으면 금액·가맹점·날짜·카테고리를 자동으로 인식해 등록하는 가계부입니다.

- 화면: 대시보드, 거래(목록/달력), 통계, 결산(월간/연간), 투자(보유 종목 · 평가손익)
- 자동 입력: 문자·알림 붙여넣기, 영수증 이미지 OCR(브라우저 내 Tesseract.js), 크롬 확장 프로그램, PWA 공유하기
- 자동 분류: 내장 규칙 + 사용자가 가르친 규칙(거래를 수정하면 학습)
- 저장: 기본은 브라우저(localStorage), 이메일 로그인(매직링크) 시 Supabase 에 동기화
- 투자 연결 준비: `ledger_holdings` 테이블과 투자 유형 거래 연동

정적 사이트(빌드 없음)라서 Vercel 에 그대로 배포됩니다.

## 크롬 확장 프로그램
`ledger-extension.zip` 을 풀고 `chrome://extensions` → 개발자 모드 → "압축해제된 확장 프로그램을 로드" 로 설치합니다.
웹페이지에서 결제 내용을 드래그 → 우클릭 → "가계부에 보내기", 이미지 우클릭 → "가계부에 영수증으로 보내기".

## Supabase 테이블
`ledger_tx`, `ledger_budgets`, `ledger_rules`, `ledger_holdings` (모두 RLS: `auth.uid() = user_id`).
